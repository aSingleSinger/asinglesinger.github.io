数据结构-树

发表于2026-05-18|更新于2026-05-19
|总字数:1.7k|阅读时长:5分钟|浏览量:

基础树结构

二叉树

每个节点最多有两个孩子：left 和 right，可以只有一个或没有

满二叉树

所有非叶子节点都有两个孩子，并且所有叶子在同一层

完全二叉树

除最后一层外都满，最后一层从左到右连续排列，不能中间空着

满的含义是这层的节点数量达到 2n−12^{n-1}2n−1

二叉搜索树(BST)

二叉搜索树是一种特殊的二叉树，满足

  • 任意节点的左子树中，所有节点的值 <<< 当前节点的值
  • 任意节点的右子树中，所有节点的值 >>> 当前节点的值
  • 左右子树也分别是二叉搜索树

特性

  • 中序遍历的结果是一个升序序列
  • 没有重复元素（或规定一侧允许等于）
  • 查找、插入、删除的时间复杂度平均为 O(log⁡n)O(\log n)O(logn)
  • 最坏情况下（退化成链表）为 O(n)O(n)O(n)

操作

查询

平均时间复杂度 O(log⁡n)O(\log n)O(logn)，最坏 O(n)O(n)O(n)

从根节点开始，小于就往左，大于就往右

插入

平均时间复杂度 O(log⁡n)O(\log n)O(logn)，最坏 O(n)O(n)O(n)

从根节点开始比较：小于当前节点，往左走；大于当前节点，往右走；走到空位置，就插进去(默认不插入重复值)。

删除

平均时间复杂度 O(log⁡n)O(\log n)O(logn)，最坏 O(n)O(n)O(n)

  1. 删除叶子节点：直接把父节点指向它的引用断开
  2. 删除只有一个孩子的节点：让它的孩子顶上来
  3. 删除有两个孩子的节点：找左子树中最大节点或者右子树最小节点(因为二叉搜索树的性质是左子树所有节点值比当前节点值小，右子树所有节点值比当前节点值大)
    所以这个地方用前驱 4 替代父节点，或者后继 7 替代父节点都可以

最大/最小值

最大值就一直向右，最小值就一直往左

总结

🐯满二叉树和完全二叉树都适合数组存，因为左孩子和右孩子以及父节点都可以直接根据下标计算，假设下标从 0 开始。堆以及优先队列

  • 当前节点 i
  • 左孩子 2i + 1
  • 右孩子 2i + 2
  • 父节点 (i - 1) / 2

🐯普通二叉树不适合数组存，因为如果某个节点少个孩子，那么对应数组位置就为 null，特别是下面这种斜二叉树，所有节点都往一侧延伸

只有 4 个节点，但是要占到下标 15 的位置

🐯普通的二叉搜索树形状非常依赖插入顺序

  • 如果第一个节点太小，后面大多数节点就会偏右；
  • 如果第一个节点太大，后面大多数节点就会偏左。

甚至可能会退化成链表，这也是为什么后面有 AVL 树以及红黑树，它们能够自动调整树的形状，避免BST退化成链表

平衡树

AVL 树

AVL 不是英文单词缩写，是人名的缩写，一般叫这个树是一种自平衡二叉搜索树

普通 BST 如果插入顺序不好，会退化成链表。这个时候查找效率接近链表 O(n)O(n)O(n)，所以 AVL 树在BST规则上多了一个要求

  • 任意节点的左右子树高度差不能超过 111
  • 左子树 < 当前节点 < 右子树 (BST要求)

AVL 树核心是平衡因子，即 平衡因子 = 左子树高度 - 右子树高度，这个值只能是 -1, 0, 1，变成别的就说明树不平衡了，需要旋转

所以，AVL 的树节点结构会多一个 height 来保存当前节点的高度信息(因为AVL树需要频繁判断 左子树高度 - 右子树高度 的值)

class AVLNode {
    int val;
    int height; // 自己作为根节点的时候树的高度

    AVLNode left;
    AVLNode right;
}

旋转

AVL 树失衡的四种情况

  1. LL 型：插入新节点导致左子树的左侧变高，左左失衡
  2. RR 型：插入新节点导致右子树的右侧变高，右右失衡
  3. LR 型：插入新节点导致左子树的右侧变高，左右失衡
  4. RL 型：插入新节点导致右子树的左侧变高，右左失衡

对应四种修复方式

  1. LL：右旋
  2. RR：左旋
  3. LR：先左旋，再右旋
  4. RL：先右旋，再左旋

操作

插入

先像 BST 一样插入，再沿修改路径向上更新 height、计算 BF 平衡因子；一旦失衡，就做对应旋转修复

注意看右旋的时候，252525 节点的右子树会给节点 303030 作为左子树

删除

先按 BST 删除(删除的节点分三种情况，无子节点，有一个子节点和两个子节点，同BST)，再沿修改路径向上更新 height、计算 BF 平衡因子；一旦失衡，就做对应旋转修复

查找/插入/删除的时间复杂度都是 O(log⁡n)O(\log n)O(logn)，因为 AVL 树始终保持平衡，树高为 O(log⁡n)O(\log n)O(logn)，更新高度、回溯检查和旋转都只发生在从修改点到根节点的一条路径上

红黑树

也是一种自平衡二叉搜索树，首先这个树也要满足 BST 规则，另外每个节点额外有一种颜色，红色或者黑色，通常还会有父节点指针

class RBNode {
    int val;
    boolean red;

    RBNode left;
    RBNode right;
    RBNode parent;
}

核心规则

  • 每个节点不是红色就是黑色
  • 根节点必须是黑色
  • 红色节点不能连续(红节点的孩子不能是红节点)
  • 从任意节点到它下面所有空叶子节点，经过的黑色节点数量相同(红黑树用这个特性来限制树不能太歪)
  • 空叶子节点 NIL 也看作黑色

红黑树为什么能保持平衡

  • 不能出现连续红节点
  • 每个路径黑色节点数量相同

它能保证最长路径不会超过最短路径的 2 倍太多，它没有 AVL 那么严格不平衡，不会退化到链表。

操作

插入

核心过程是

  1. 新节点先插入变成红色，如果父黑则结束(因为这样不会改变每条路黑节点数量)
  2. 父红+叔红，父和叔都变黑，祖父变红，然后再往上走，根必须为黑
  3. 父红+叔黑，旋转并且变色(父和祖都变)

删除

查询和修改节点值，不改变树结构，不会触发旋转或者颜色调整
